# 🛒 BazarDor (Market Price Rate)

A modern web application designed to track the accurate market prices of daily essential commodities, provide market-based price comparisons, and deliver live updates on daily price fluctuations.

## Technologies Used
- **Next.js (App Router)** – For building the user interface and handling routing.
- **Tailwind CSS** – For styling and ensuring a responsive design.
- **TypeScript** – For maintaining strict type safety.
- **BetterAuth** – For secure user authentication and session management.
- **Lucide React** – For a modern and clean icon set.

## Key Features
1. **Live Price Ticker:** A dynamic scrolling strip below the navbar that displays real-time information, including the product name, price, and percentage change.
2. **Market-wise Price Breakdown:** A protected Product Details page showcasing the minimum, maximum, and average prices of a specific product, alongside a breakdown of prices across different markets.
3. **Smart Sorting & Filtering:** Easily organize products based on price, from lowest-to-highest or highest-to-lowest.
4. **Secure Authentication:** A protected routing system featuring reliable Sign In and Sign Up options using Email/Password.
5. **Fully Responsive Design:** A beautifully optimized user interface that adapts seamlessly across mobile, tablet, and desktop devices.
